# football-copy-check · 足球文案查重库

抖音足球账号矩阵的文案查重工具。防止同一文案在多设备/多账号重复发布,被平台判定搬运。

## 为什么需要

- 多设备多账号发同主题内容,文案高度相似会被抖音查重打击
- 豆包批量生成文案容易产出结构雷同的文本
- 库里记录所有发过的文案,新文案先查再发,重复率可控

## 使用方法

```bash
# 查重(发布前必做)
python3 check.py "要查重的文案"

# 查重 + 入库(通过后自动追加到库)
python3 check.py --add "新文案" --match "英超 阿森纳vs曼城" --source 豆包

# 强制入库(相似度中风险但决定使用)
python3 check.py --add "文案" --match "赛事" --force

# 查看全部/统计
python3 check.py --list
python3 check.py --stats
```

## 判定标准

| 相似度 | 结论 | 处理 |
|--------|------|------|
| >= 80% | 高风险 | 必须重写,禁止发布 |
| 60%~79% | 中风险 | 修改措辞后再发 |
| < 60% | 安全 | 可直接发布 |

## 数据

- 文案库:`data/copywriting.jsonl`,每行一条 JSON 记录
- 字段:`date` 入库时间、`match` 赛事标签、`source` 来源、`text` 文案全文

## 懂球帝评论区抓取（skill）

素材来源工具：`skills/dongqiudi-comments/`，从懂球帝文章页评论区抓取真实球迷观点，供文案提炼。

```bash
# 单篇（ID 或 URL）
python3 skills/dongqiudi-comments/scripts/fetch_comments.py 6225262

# 按赞排序 + 过滤水评
python3 skills/dongqiudi-comments/scripts/fetch_comments.py 6225049 --sort up --min-up 5

# 批量 JSON 输出（供下游分析）
python3 skills/dongqiudi-comments/scripts/fetch_comments.py 6225262 6225049 --json
```

能力与边界：抓用户名/赞/回复/时间/内容，游标翻页拿热门子集（约 40-50 条/篇），
`实抓/总数` 对账透明；全量接口不开放，见 `SKILL.md`。

## 说明

- 本库只防"自我重复"。全网查重(别人抄你/你抄别人)需配合抖音站内搜索验证
- 仓库为私有(2026-08-24 转私有,防同行举报/参考),文案仅本账号矩阵自产自用
